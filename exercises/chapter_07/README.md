# 第7章 - 函数

## 课后问题

### 问题 7.1
具有空函数体的函数可以作为存根使用。你如何对这类函数进行修改，使其更加有用？

**答案**：可以添加打印语句来跟踪函数调用，或者返回一个合理的默认值。

```c
void stub_function(void) {
    printf("stub_function called\n");
}
```

---

### 问题 7.2
在ANSI C中，函数的原型并非必需。请问这个规定是优点还是缺点？

**答案**：缺点。没有原型，编译器无法检查参数类型和数量是否正确，容易导致难以发现的错误。这是为了兼容旧代码而保留的特性。

---

### 问题 7.3
如果在一个函数的声明中，它的返回值类型为A，但它的函数体内有一条return语句，返回了一个类型为B的表达式。请问，这将导致什么后果？

**答案**：编译器会尝试将类型B隐式转换为类型A。如果转换可行，可能丢失精度；如果不可行，编译错误。

---

### 问题 7.4
如果一个函数声明的返回类型为void，但它的函数体内包含了一条return语句，返回了一个表达式。请问，这将导致什么后果？

**答案**：编译错误。void函数不能返回值。

---

### 问题 7.5
如果一个函数被调用之前，编译器无法看到它的原型，那么当这个函数返回一个不是整型的值时，会发生什么情况？

**答案**：编译器假定函数返回int类型。如果实际返回类型不同，会导致未定义行为，可能得到错误的结果或程序崩溃。

---

### 问题 7.6
如果一个函数被调用之前，编译器无法看到它的原型，如果当这个函数被调用时，实际传递给它的参数与它的形式参数不匹配，会发生什么情况？

**答案**：参数会按照默认参数提升规则传递，可能导致参数传递错误，产生未定义行为。

### 问题 7.8
递归和while循环之间是如何相似的？

**答案**：
- 都需要终止条件
- 都通过重复执行相同操作来解决问题
- 每次迭代/递归都向终止条件靠近
- 都可以用于处理重复性任务

---

### 问题 7.9
请解释把函数原型单独放在#include文件中的优点。

**答案**：
- 便于维护：修改原型只需改一处
- 便于复用：多个源文件可以共享同一头文件
- 类型安全：编译器可以检查函数调用是否正确
- 文档化：头文件可以作为接口文档
