# 第3章 - 数据

## 章节简介

本章主要介绍C语言的基本数据类型，包括整型家族、浮点型、指针、常量、作用域和存储类型等。

## 课后问题（共23道）

### 3.1 字符和整数类型

**问题1**：在你的机器上，字符的范围有多大？有哪些不同的整数类型？它们的范围又是如何？

**答**：使用 `<limits.h>` 查看：

```c
#include <stdio.h>
#include <limits.h>

int main() {
    printf("char: %d ~ %d\n", CHAR_MIN, CHAR_MAX);
    printf("int: %d ~ %d\n", INT_MIN, INT_MAX);
    printf("short: %d ~ %d\n", SHRT_MIN, SHRT_MAX);
    printf("long: %ld ~ %ld\n", LONG_MIN, LONG_MAX);
    return 0;
}
```

---

### 3.2 浮点数范围

**问题2**：在你的机器上，各种不同类型的浮点数的范围是怎样的？

**答**：使用 `<float.h>` 查看：

```c
#include <stdio.h>
#include <float.h>

int main() {
    printf("float: %e ~ %e\n", FLT_MIN, FLT_MAX);
    printf("double: %e ~ %e\n", DBL_MIN, DBL_MAX);
    printf("long double: %Le ~ %Le\n", LDBL_MIN, LDBL_MAX);
    return 0;
}
```

### 3.3 跨平台整型声明

**问题3**：假定你正编写一个程序，它必须运行于两台机器之上。这两台机器的缺省整型长度并不相同，一个是16位，另一个是32位。而这两台机器的长整型长度分别是32位和64位。程序所使用的有些变量的值并不太大，足以保存于任何一台机器的缺省整型变量中，但有些变量的值却较大，必须是32位的整型变量才能容纳它。

**答**：使用 `<stdint.h>` 定义固定宽度类型：

```c
#include <stdint.h>

int16_t small_val;   // 16位，足够小值
int32_t large_val;   // 32位，较大值
```

### 3.4 long → short 赋值

**问题4**：假定你有一个程序，它把一个long整型变量赋值给一个short整型变量。当你编译程序时会发生什么情况？当你运行程序时会发生什么情况？

**答**：

```c
long l = 100000;
short s = (short)l;  // 隐式转换，可能有警告

// 编译：可能有警告
// 运行：截断，100000 超出 short 范围(-32768~32767)
```

### 3.5 double → float 赋值

**问题5**：假定你有一个程序，它把一个double变量赋值给一个float变量。当你编译程序时会发生什么情况？当你运行程序时会发生什么情况？

**答**：

```c
double d = 3.14159265358979;
float f = d;  // 精度损失

// 编译：可能警告
// 运行：精度降低（float只有6-7位有效数字）
```

### 3.7 代码段输出

**问题7**：下列代码段会打印出什么东西？

```c
int i, j;
i = 10;

printf("%d %d", i, j);
```

**答**：打印 `11 11`（先加加，后使用）

### 3.8 字符串常量

**问题8**：你所使用的C编译器是否允许程序修改字符串常量？是否存在编译器选项，允许或禁止你修改字符串常量？

### 3.9 signed 关键字

**问题9**：如果整数类型在正常情况下是有符号类型，那么signed关键字的目的何在呢？

**答**：明确指定为有符号，消除歧义：

```c
char c;           // 有符号还是无符号？不确定
signed char sc;   // 明确为有符号
```

---

### 3.10 无符号 vs 有符号

**问题10**：一个无符号变量可不可以比相同长度的有符号变量容纳更大的值？

**答**：可以。无符号范围是 0~2^N-1，有符号是 -2^(N-1) ~ 2^(N-1)-1

```c
unsigned int: 0 ~ 4294967295
signed int:   -2147483648 ~ 2147483647
```

---

### 3.11 int vs float 精度

**问题11**：假如int和float类型都是32位长，你觉得哪种类型所能容纳的值精度更大一些？

**答**：int 精度更大。

- int：精确表示32位整数
- float：1位符号 + 8位指数 + 23位尾数，只能精确表示约24位整数

### 3.12 初始化方式

**问题12**：下面两个代码片段完成任务的方式有何不同？

```c
int a = 25;   // 方式1
// vs
int a;        // 方式2
a = 25;
```

**答**：
- 方式1：编译时初始化，值存在数据段
- 方式2：运行时赋值，需要额外指令

---

### 3.13 const 初始化

**问题13**：如果问题12中代码片段的声明中包含有const关键字，它们完成任务的方式又有何不同？

**答**：
- const 静态变量：必须在编译时初始化
- const 自动变量：运行时赋值

```c
const int a = 25;   // 必须是常量表达式
```

### 3.14 代码块作用域

**问题14**：在一个代码块内部声明的变量可以从该代码块的任何位置根据名字来访问，对还是错？

**答**：错。只能在声明之后到代码块结束之间访问。

### 3.15 extern 访问自动变量

**问题15**：假定函数a声明了一个自动整型变量x，你可以在其他函数内访问变量x，只要你使用了下面这样的声明：`extern int x;`

**答**：错。自动变量生命周期在函数内，extern 无法访问。

---

### 3.16 static 变量 + extern

**问题16**：假定问题15中的变量x被声明为static。你的答案会不会有所变化？

**答**：仍然是错。static 只改变存储方式，不改变作用域。

---

### 3.17 文件作用域访问

**问题17**：假定文件a.c的开始部分有下面这样的声明：`int x;` 如果你希望从同一个源文件后面出现的函数中访问这个变量，需不需要添加额外的声明？

**答**：不需要。文件作用域变量对整个文件可见。

---

### 3.18 static 文件作用域

**问题18**：假定问题17中的声明包含了关键字static。你的答案会不会有所变化？

**答**：仍然是，不需要额外声明。static 只改变链接属性（不可见其他文件）。

---

### 3.19 跨文件访问

**问题19**：假定文件a.c的开始部分有下面这样的声明：`int x;` 如果你希望从不同的源文件的函数中访问这个变量，需不需要添加额外的声明？

**答**：需要。在其他文件中用 `extern int x;` 声明。

---

### 3.20 static 跨文件

**问题20**：假定问题19中的声明包含了关键字static。你的答案会不会有所变化？

**答**：变化。static 使变量链接属性变为 internal，无法跨文件访问。

---

### 3.21 自动变量值

**问题21**：假定一个函数包含了一个自动变量，这个函数在同一行中被调用了两次。试问，在函数第2次调用开始时该变量的值和函数第1次调用即将结束时的值有无可能相同？

**答**：有可能。自动变量在函数结束时销毁，再次调用是全新分配。

---

### 3.22 代码块内外声明

**问题22**：当下面的声明出现于某个代码块内部和出现于任何代码块外部时，它们在行为上有何不同？

```c
int a = 5;
```

**答**：
- 代码块外部：静态存储，程序开始分配，生命周期整个程序
- 代码块内部：自动存储，函数调用时分配，函数结束释放

## 总结

本章为概念章节，无编程练习。重点理解：
- 整型家族：char, short, int, long
- 有符号(signed) vs 无符号(unsigned)
- sizeof 查看大小，limits.h 查看范围
- 指针是存储地址的特殊类型
- 作用域：代码块、文件、原型、函数
- 存储类型：auto, static, register, extern
