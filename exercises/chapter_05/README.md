### 问题 5.1
下面这个表达式的类型和值分别是什么？
```c
(float)(25 / 10)
```

**答案**：类型是float，值是2.0。因为25/10是整数除法，结果为2，然后转换为float。

### 问题 5.5
用一条赋值语句判断闰年。

**答案**：
```c
leap_year = ((year % 4 == 0 && year % 100 != 0) || year % 400 == 0);
```

### 问题 5.12
如何判断在你的机器上对一个有符号值进行右移位操作时执行的是算术移位还是逻辑移位？

**答案**：
```c
int x = -1;
if (x >> 1 == -1)
    printf("算术移位\n");
else
    printf("逻辑移位\n");
```
