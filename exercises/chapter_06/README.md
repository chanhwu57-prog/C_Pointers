# 第6章 - 指针

## 课后问题

### 问题 6.1
如果一个值的类型无法简单地通过观察它的位模式来判断，那么机器是如何知道应该怎样对这个值进行操纵的？

**答案**：通过类型信息。编译器根据变量的类型声明生成相应的机器指令，指示CPU如何解释和处理数据。

---

### 问题 6.2
C为什么没有一种方法来声明字面值指针常量呢？

**答案**：因为指针值依赖于运行时的内存布局，在编译时无法确定有效的指针值。只有NULL是一个特殊的指针常量。

---

### 问题 6.3
假定一个整数的值是244。为什么机器不会把这个值解释为一个内存地址呢？

**答案**：因为类型信息告诉机器这是一个整数，不是指针。类型决定了如何解释存储的位模式。

---

### 问题 6.4
在有些机器上，编译器在内存位置零存储0这个值。对NULL指针进行解引用操作将访问这个位置。这种方法会产生什么后果？

**答案**：可能导致程序崩溃或未定义行为。有些机器允许访问地址0，这会隐藏错误；有些机器会触发异常。

### 问题 6.6
下面的代码段有没有问题？如果有的话，问题在哪里？
```c
int array[ARRAY_SIZE];
int *pi;
for (pi = &array[0]; pi < &array[ARRAY_SIZE];)
    *++pi = 0;
```

**答案**：有问题！`*++pi` 先自增pi，然后解引用。这意味着：
1. 第一个元素array[0]不会被初始化
2. 最后一次循环会越界访问array[ARRAY_SIZE]

应该改为：
```c
for (pi = &array[0]; pi < &array[ARRAY_SIZE]; pi++)
    *pi = 0;
```
