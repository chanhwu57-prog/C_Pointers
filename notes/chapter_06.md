# 第6章：指针

## 学习目标

- 深入理解指针的概念和用法
- 掌握指针运算和间接访问
- 学会正确使用指针避免常见错误

---

## 6.1 内存和地址

计算机内存可以看作是一系列存储单元，每个单元有唯一地址。

**关键概念**：
- 每个内存位置由唯一地址标识
- 每个内存位置包含一个值
- 高级语言通过名字（变量名）访问内存位置

---

## 6.2 值和类型

变量的值存储在内存中，类型决定了如何解释这些值。

```c
int a = 112;    // 整数
float b = 3.14; // 浮点数
char c = 'A';   // 字符
```

---

## 6.3 指针变量的内容

指针变量存储的是另一个变量的地址。

```c
int a = 112;
int *d = &a;    // d存储a的地址
```

**图示**：
```
变量    地址    值
a       100     112
d       104     100  (指向a的地址)
```

---

## 6.4 间接访问操作符

`*` 是间接访问操作符（解引用），通过指针访问它所指向的值。

```c
int a = 112;
int *d = &a;

printf("%d\n", *d);  // 输出 112
*d = 200;            // 修改a的值为200
```

**理解**：
- `&a` 获取变量a的地址
- `*d` 通过地址访问值

---

## 6.5 未初始化和非法的指针

**危险**：未初始化的指针包含随机值，解引用会导致未定义行为。

```c
int *a;         // 未初始化，包含随机地址
*a = 12;        // 危险！写入随机内存位置
```

**正确做法**：

```c
int *a;
int b;
a = &b;         // 让a指向有效的变量
*a = 12;        // 安全
```

---

## 6.6 NULL指针

NULL指针不指向任何有效内存位置。

```c
int *p = NULL;

if (p != NULL) {
    *p = 10;    // 只有非NULL时才解引用
}
```

**用途**：
- 表示指针尚未指向有效对象
- 作为函数返回值表示失败
- 作为数组或链表的终止标志

---

## 6.7 指针、间接访问和左值

指针表达式可以作为左值：

```c
int a;
int *d = &a;

*d = 10;    // *d是左值，等价于 a = 10
```

---

## 6.8 指针、间接访问和变量

```c
int a = 10;
int *b = &a;
int **c = &b;   // 指向指针的指针

printf("%d\n", a);   // 10
printf("%d\n", *b);  // 10
printf("%d\n", **c); // 10
```

---

## 6.9 指针常量

```c
int a;
int * const p = &a;     // 常量指针：p本身不能修改
const int *q = &a;      // 指向常量的指针：*q不能修改
const int * const r = &a; // 两者都是常量
```

---

## 6.10 指针的指针

```c
int a = 10;
int *b = &a;     // b指向a
int **c = &b;    // c指向b

printf("%d\n", **c);  // 10
```

**理解**：
- `c` 是指向指针的指针
- `*c` 得到 `b`（指向a的指针）
- `**c` 得到 `a` 的值

---

## 6.11 指针表达式

```c
char ch = 'a';
char *cp = &ch;
```

| 表达式 | 值 | 类型 |
|--------|-----|------|
| `ch` | 'a' | char |
| `&ch` | ch的地址 | char * |
| `cp` | ch的地址 | char * |
| `*cp` | 'a' | char |
| `*cp + 1` | 'b' | int |
| `*(cp + 1)` | ch后面的字符 | char |
| `++cp` | 下一个地址 | char * |
| `*++cp` | 下一个字符 | char |
| `cp++` | 当前地址 | char * |
| `*cp++` | 当前字符，然后cp后移 | char |

---

## 6.12 实例：字符串长度

```c
int strlen(char *str) {
    int len = 0;
    while (*str++ != '\0')
        len++;
    return len;
}
```

---

## 6.13 指针运算

### 算术运算

```c
int arr[5] = {1, 2, 3, 4, 5};
int *p = arr;

p++;        // p指向arr[1]
p += 2;     // p指向arr[3]
int diff = p - arr;  // diff = 3
```

**注意**：指针加减整数时，实际移动的字节数取决于指针类型。

```c
char *cp;
int *ip;
double *dp;

cp + 1;  // 移动1字节
ip + 1;  // 移动4字节（假设int为4字节）
dp + 1;  // 移动8字节
```

### 关系运算

```c
int arr[10];
int *p = arr;
int *end = arr + 10;

while (p < end) {
    *p++ = 0;
}
```

**警告**：只能对同一数组内的指针进行比较！

---

## 6.14 总结

| 概念 | 说明 |
|------|------|
| 指针 | 存储地址的变量 |
| `&` | 取地址操作符 |
| `*` | 间接访问操作符 |
| NULL | 空指针常量 |
| 指针运算 | 加减整数、指针相减、比较 |

## 课后问题

### 问题 6.1

**问**：下面的代码有什么问题？

```c
int *a;
*a = 12;
```

**答**：指针a未初始化，包含随机地址。解引用会导致未定义行为。

---

### 问题 6.2

**问**：`*p++` 和 `(*p)++` 有什么区别？

**答**：
- `*p++`：返回p指向的值，然后p自增
- `(*p)++`：p指向的值自增，p不变

---

### 问题 6.3

**问**：如何判断两个指针是否指向同一个对象？

**答**：直接比较指针值：

```c
if (p == q) {
    // 指向同一个对象
}
```
