## 8.1 一维数组

### 8.1.1 数组名

**关键概念**：在表达式中，数组名是指向数组第一个元素的指针常量。

```c
int a;
int b[10];
```

- `a` 是标量，类型是 `int`
- `b` 是数组，在表达式中 `b` 的类型是 `int *`（指向第一个元素）

**例外**：
- `sizeof(b)` 返回整个数组的大小，不是指针大小
- `&b` 返回指向数组的指针，类型是 `int (*)[10]`

```c
int arr[10];
int *p = arr;      // 合法：arr是指向arr[0]的指针
arr = p;           // 非法：arr是常量，不能修改
```

---

### 8.1.2 下标引用

**下标引用和间接访问等价**：

```c
array[subscript]
*(array + subscript)
```

这两个表达式完全相同！

```c
int array[10];
int *ap = array + 2;  // ap指向array[2]

ap[0]     // 等价于 array[2]
ap[6]     // 等价于 array[8]
ap[-1]    // 等价于 array[1]
2[array]  // 等价于 array[2]！（合法但奇怪）
```

**警告**：C不进行下标边界检查！

```c
int arr[10];
arr[10] = 0;   // 越界访问，未定义行为
arr[-1] = 0;   // 越界访问，未定义行为
```

---

### 8.1.3 指针与下标

指针通常比下标更高效：

```c
// 下标版本
for (int i = 0; i < 10; i++)
    array[i] = 0;

// 指针版本
for (int *p = array; p < array + 10; p++)
    *p = 0;
```

---

### 8.1.4 作为函数参数的数组名

数组名作为参数时，传递的是指针：

```c
void func(int arr[]) {  // 等价于 int *arr
    // arr是指针，不是数组
}
```

```c
void strcpy(char *dest, const char *src) {
    while ((*dest++ = *src++) != '\0')
        ;
}
```

---

### 8.1.5 数组初始化

```c
int arr[5] = {1, 2, 3, 4, 5};
int arr[] = {1, 2, 3};        // 自动计算长度为3
int arr[5] = {1, 2};          // 其余元素初始化为0
int arr[5] = {0};             // 全部初始化为0
```

**字符数组初始化**：

```c
char str[] = "Hello";         // 长度为6，包含'\0'
char str[] = {'H', 'e', 'l', 'l', 'o', '\0'};
```

## 8.2 多维数组

### 8.2.1 存储顺序

C语言中多维数组按**行主序**存储：

```c
int matrix[3][4];
```

内存布局：`matrix[0][0], matrix[0][1], ..., matrix[0][3], matrix[1][0], ...`

### 8.2.2 数组名

```c
int matrix[3][10];
```

- `matrix` 指向第一行，类型是 `int (*)[10]`
- `matrix[0]` 指向第一行第一个元素，类型是 `int *`
- `matrix[1][2]` 是一个整数

### 8.2.3 初始化

```c
int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

int matrix[2][3] = {1, 2, 3, 4, 5, 6};  // 等价
```

## 8.3 指针数组

```c
int *arr[10];  // 包含10个int指针的数组
```

**用途**：处理多个字符串

```c
char *strings[] = {
    "Hello",
    "World",
    "C Programming"
};
```

---

## 8.4 总结

| 概念 | 说明 |
|------|------|
| 数组名 | 表达式中是指向第一个元素的指针常量 |
| 下标引用 | 等价于间接访问 |
| 多维数组 | 按行主序存储 |
| 指针数组 | 元素是指针的数组 |
| 数组参数 | 传递的是指针，不是整个数组 |

## 课后问题

### 问题 8.1

**问**：`arr` 和 `&arr[0]` 有什么区别？

**答**：值相同，但类型不同：
- `arr`：类型是 `int *`（指向第一个元素）
- `&arr[0]`：类型也是 `int *`

但 `&arr` 类型是 `int (*)[n]`（指向整个数组）。

---

### 问题 8.2

**问**：为什么不能将一个数组赋值给另一个数组？

**答**：数组名是指针常量，不能被修改。必须逐元素复制：

```c
for (int i = 0; i < n; i++)
    dest[i] = src[i];
```

---

### 问题 8.3

**问**：`int arr[3][4]` 和 `int *arr[4]` 有什么区别？

**答**：
- `int arr[3][4]`：二维数组，连续存储12个整数
- `int *arr[4]`：指针数组，包含4个指针
