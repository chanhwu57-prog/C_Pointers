# C与指针学习仓库

## 仓库目的

本仓库用于存放《C与指针》一书的学习笔记和课后习题解答，帮助初学者系统学习C语言和指针相关知识。

4. 第4章：控制流语句

## 学习方法

1. **理论学习**：阅读《C与指针》对应章节，理解核心概念
2. **代码实践**：完成课后习题，编写和运行代码
3. **笔记总结**：记录重要概念和学习心得
4. **项目实践**：通过小型项目巩固所学知识
5. **代码审查**：定期回顾和优化已写代码

## 环境配置

### 编译环境
- **Windows**：MinGW 或 Visual Studio
- **macOS**：Xcode Command Line Tools
- **Linux**：GCC

### 推荐工具
- **编辑器**：VS Code, Sublime Text, Vim
- **版本控制**：Git
- **调试工具**：GDB (Linux/macOS), WinDbg (Windows)
